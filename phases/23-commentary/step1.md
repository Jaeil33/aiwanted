# Step 1: safety-threshold

## 왜

사용자 요청(작업 도중): *"사생활의 기준치를 좀 낮출 필요는 있을것 같아. 범죄. 이런건 안되지만, 여자친구랑 헤어짐, 화장실에 가고싶음. 배가 아픔. 이정도는 괜찮아. 유머 요소로 활용될 수 있어야해."*

이 앱의 재료는 "쓸데없는 변수"인데, **제일 쓸데없고 제일 웃긴 축을 거부하고 있었다.** 실제로 재 보니 앞뒤도 안 맞았다:

| 문장 | 전 | 후 |
|---|---|---|
| 타자가 화장실에 가고 싶다 | allow | allow |
| 타자가 갑자기 똥이 마려웠다 | allow | allow |
| 타자가 배탈이 났다 | **block** (illness) | allow |
| 타자가 배가 아프다 | **block** (illness) | allow |
| 김타자가 여자친구랑 헤어졌다 | **block** (privacy) | allow |
| 타자가 소개팅을 했다 | **block** (privacy) | allow |

화장실은 통과하는데(사전에 없어서) 배탈은 막혔다. 같은 농담인데 낱말 하나 차이로 갈렸다.

## 기준을 바꿨다

**"얼마나 사적인가" → "실존 선수에게 씌우면 해가 되는가"**(ADR-040).

이 앱은 실명으로 공개 배포된다(ADR-005). 위험한 것은 사적이라는 사실 자체가 아니라, **없는 사실을 실존 선수에게 씌워 퍼뜨리는 것**이다. 그 선으로 다시 그으면:

- `배가 아팠대` = 농담 / `어깨가 아프다` = **부상 주장**
- `여친이랑 헤어졌대` = 농담 / `불륜설` = **명예 문제**

### "아프다"는 아픈 곳으로 가른다

경기에 쓰는 부위(어깨·팔꿈치·손목·무릎·허리·햄스트링…)가 아프다는 말은 `injury`로 막는다. 부위 목록을 injury 사전에 넣었다 — 전에는 일반 `아프`가 `illness`로 잡던 것을 이제 부위가 있으면 injury가 먼저 가져간다.

배·속은 `ALLOWED_PHRASES`에서 먼저 지운다. 지워야 아래 `illness`의 일반 `아프`에 안 걸린다.

### 그대로 막는 것

범죄·음주·도박·폭력·약물·사망·성적 내용·비하, 그리고 이혼·불륜·임신·열애설·모텔·신상·금전(파산·사채), 진짜 병(암·우울증·코로나·장염·입원).

## 사전에 개념을 냈다

기준만 낮추면 통과는 하는데 **말이 안 되는 효과**가 났다. 규칙 해석이 문장 분위기로 때우기 때문이다:

```
박투수 배탈 났다        → pitcher:stamina +1   ← 배탈인데 체력이 오른다
박투수 데이트 하다 늦었다 → pitcher:control +1
```

그래서 개념 셋을 넣었다.

| 개념 | 타자 | 투수 |
|---|---|---|
| `body-tummy` (배탈·복통·설사·배가 아프다·속쓰림) | `power` −2 "배에 힘이 안 들어간다" | `stamina` −2 "길게 끌고 갈 몸이 아니다" |
| `love-heartache` (이별·헤어짐·차였다·짝사랑) | `focus` −2 "공보다 딴 생각이 먼저" | `nerve` −2 "마운드에서 마음이 흔들린다" |
| `love-dating` (연애·여친·소개팅·데이트·고백) | `focus` +1 "발걸음이 가볍다" | `nerve` +1 "마음 편히 던진다" |

`love-heartache`가 `love-dating`을 `excludes`한다 — "여자친구랑 헤어졌다"는 둘 다 걸리지만 이별이 이긴다.

곁다리로 `sleep-oversleep`에 `늦었다`를 넣었다. 어느 개념에도 안 걸리던 낱말이라 "데이트 하다 늦었다"가 기분 좋은 일로만 읽혔다. 이제 둘 다 잡는다:

```
박투수 데이트 하다 늦었다 → pitcher:nerve +2, pitcher:stamina −2
```

### 팀 손잡이는 개인에게 못 건다

처음엔 연애를 `mood`(팀 분위기)로 뒀는데 `김타자 여친 생김 → battingTeam:mood +2`가 나왔다. 개인 이야기가 팀 전체에 걸렸다. `mood`는 `who: 'team'`이라 `SUBJECTS_FOR`가 개인을 안 준다 — 타자는 `focus`, 투수는 `nerve`로 바꿨다.

## AI 쪽도 같이

`buildInterpretPrompt`가 아직 "사생활이 담기면 refused"라고 말하고 있었다. 배포에는 AI가 켜져 있으니 규칙만 고치면 **로컬은 통과하고 배포는 거부하는** 상태가 된다. 프롬프트에 새 선을 적었다(사생활은 해가 되는 것만, "아프다"는 아픈 곳으로).
