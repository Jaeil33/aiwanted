# Step 2: caption

## 왜

step 0이 자막을 **만들 수는** 있게 했지만 아무도 부르지 않았고, 아무 데도 안 그렸다. 이 step이 둘을 잇는다.

## 어디에

중계 자막이 있어야 할 자리 — **타자·투수 줄(64px) 바로 위, 경기장 아래쪽.**

```
┌ 트래커 ─────────────────────────┐
│                                 │
│           (경기장)               │
│                                 │
│ ▌해설│ 어제 여자친구랑 헤어진      │  ← 노란 띠 + "해설" 표, 13px 두 줄
│      │ 고준휘, 삼진으로 물러납니다 │
│ ▌고준휘 우타      하영민 우투 ▐  │  ← 원래 있던 타자·투수 줄
└─────────────────────────────────┘
```

`PitchTracker`에 `commentary` prop 하나를 더했다. 자막이 없으면 아예 안 그린다 — 빈 띠가 경기장을 가리지 않는다.

## 언제 뜨고 언제 사라지나

| | |
|---|---|
| **뜬다** | 타석이 끝나면(`session.log`가 늘면) `PlayScreen`이 `actions.narrate()`를 부른다 |
| **사라진다** | 다음 공이 날아갈 때(`animationStart`). 리듀서가 지운다 — 타석 사이에 읽을 시간을 준다 |
| **안 뜬다** | 걸린 TMI가 없으면. `narrate`가 자리도 잡지 않는다 |

받는 중에는 `해설을 받는 중…`을 대신 둔다. **반짝이지 않는다**(UI_GUIDE 원칙 6: 움직임은 결과를 알릴 때만). 들어올 때 6px 올라오는 260ms 하나뿐이다.

## 화면에 자막은 하나뿐

`session.call`은 `{ paIndex, result }` 하나다. 새 타석이 끝나면 `narrate`가 앞 요청을 끊고(`AbortController`) 새로 부른다. 늦게 온 앞 타석 자막은 리듀서가 버린다(`callDone`의 `paIndex`가 안 맞으면 같은 객체).

그래서 **"경기 끝까지"로 타석이 쏟아져도 AI 호출은 사실상 한 번**이다.

`calledPa` ref가 `${situation.id}|${seed}|${paIndex}`를 기억한다 — StrictMode가 효과를 두 번 돌려도 AI는 한 번만 부른다. `resetPlay`·`openSituation`에서 비운다.

## 재료 (`callFactsOf`)

순수 함수다. 마지막 로그 줄에서 이닝·타자·투수·결과·점수를 옮기고, **확률은 옮기지 않는다**(`wpHomeAfter`를 버린다 — 자막은 숫자를 말하지 않는다).

점수는 직전 타석과의 차이다. 첫 타석은 장면 시작 점수와 견준다.

걸린 TMI를 고르는 규칙은 `compileSessionEffects`와 같다: 거부된 것은 빼고, 타석 한정(`scope: 'pa'`) 효과는 그것을 건 타석에만, 나머지는 경기 내내(ADR-033).

## 못 한 확인

브라우저 창이 뒤에 있으면 `requestAnimationFrame`이 멈춰 투구 연출이 끝나지 않는다. 그래서 **실제로 한 타석을 끝까지 쳐서 자막이 붙는 것은 브라우저에서 못 봤다.** 대신 그 경로는 테스트가 덮는다(`PlayScreen 해설 자막` 셋: 붙는다 / TMI 없으면 안 붙는다 / 다음 공에 사라진다). 자막 자체의 크기·색·자리는 위처럼 실제 페이지에서 쟀다.
