# Step 1: unlock-team

## 왜

사용자 피드백 2번: **"한번 응원팀으로 들어간다고 해서 나왔을때 계속 그팀만 보게끔 되어있는것 같은데 없애."**

원인은 둘이었다. 하나만 고치면 잠금이 남는다.

1. **`TeamsScreen`이 누른 팀을 저장했다.** LG 일정을 한 번 보려고 누르면 LG가 영영 응원팀이 됐다.
   보는 것과 응원하는 것이 같은 단추였다.
2. **`HomeScreen`이 응원팀으로 피드를 걸렀다.** `gamesOfTeam(games, team)`. 팀이 정해지는 순간
   홈에서 리그의 나머지가 사라졌다.

## 작업

### 보는 것 ≠ 응원하는 것
- `TeamsScreen`: 타일이 **링크**다. 누르면 `#/team/:code`로 갈 뿐 저장하지 않는다. 응원팀에는 "내 팀" 표.
- `TeamScreen`: 머리말에 `응원팀으로` / `내 팀` 토글(`aria-pressed`). **응원팀은 여기서만 바뀐다.**

### 홈은 늘 리그 전체
- `gamesOfTeam(games, filtered ? team : null)` — 기본은 전체. 피드 경기 수 3 → **5**(하루 다섯 경기 = 최근 한 경기일).
- 응원팀이 있으면 `전체` / `LG만` 두 칩. **저장하지 않는다** — 다시 들어오면 전체다.
  저장하는 값은 여전히 응원팀 하나뿐(ADR-034).
- 응원팀이 있든 없든 `구단 일정`(`#/teams`) 링크가 늘 있다. 있으면 `LG 일정`이 하나 더 는다.

## 함정 하나

`<i/>{이름}<em>내 팀</em>`의 읽어 주는 이름은 `"롯데내 팀"`이다 — 사이에 공백 노드가 없으면 붙는다.
`{' '}`를 넣는다. 플렉스는 공백만 있는 노드를 칸으로 세지 않아 화면은 그대로다.
