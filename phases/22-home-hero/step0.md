# Step 0: hero

## 왜

배포본(`https://aiwanted.vercel.app`) 첫 화면을 390px에서 실제로 찍어 보니 **이 앱이 무엇인지 말하는 자리가 없었다.**

화면에 있던 것은 브랜드 글자, 14px 회색 부제 한 줄, 구단 띠, 경기 카드 다섯이 전부다. **정체성인 TMI가 홈에 한 글자도 없다.** 처음 연 사람에게 이건 경기 기록 앱이다 — 쓸데없는 한 줄로 확률을 바꾸는 게임이라는 걸 알아낼 방법이 첫 화면에 없다.

세 가지가 겹쳐 있었다.

| | 그 전 |
|---|---|
| 앱 소개 | 14px `--text-3` 한 줄 |
| `--accent`(#FFD23F) | 브랜드 "야구" 글자 + 승부처 줄 3px 테두리뿐 |
| 첫 1.75초 | 승부처가 붙기 전이라 **빈 상자 다섯 개** (실측: 따뜻한 캐시에서 1,752ms) |

## 한 일

경기 목록·구단 띠·탭바·스코어 카드는 **한 줄도 안 건드리고** 맨 위에 히어로만 얹었다.

```
쓸모없는 변수, 진짜 쓸모없을까?      12px --text-3   (부제는 남긴다)
방금 그 타석,                       28px 900
만약 그랬다면?                      28px 900 --accent
쓸데없는 TMI 한 줄이면 …             13px --text-2
[“짜장면 곱빼기”] [“3시간밖에”] […]   가로 스크롤 칩
[    아무 타석에나 TMI 걸기    ]      52px 꽉 찬 --accent
```

### 예시 칩은 장식이 아니라 한 탭 데모다

공유 값(`?t=`)이 이미 TMI 문장을 싣고 다닌다(`src/game/share.ts`). 그래서 칩 하나 누르면 **그 문장이 걸린 실제 타석이 열리고 확률이 이미 움직여 있다.** 새로 지은 것은 없다 — `encodeShare`·`situationIdOf`·`formatRoute`가 전부 이미 있었고 테스트도 있었다.

실제로 확인한 한 판: `“경기 전에 짜장면 곱빼기를 먹었다”` → 9/25 한화-NC 1회말 무사 1·2루(박민우 vs 화이트) → **타자 집중력 ↓, NC 승리확률 62.5% → 59.6% (−2.8%p)**.

네 문장 모두 규칙 사전이 실제로 잡는 것만 골랐다(음식·잠·날씨·징크스). AI 키가 없어도 눌렀을 때 효과가 난다 — 배포에서 AI가 꺼져 있던 전례가 있다(ADR-028).

**실존 선수 이름은 쓰지 않는다.** 공개 저장소이고 공개 배포다(ADR-005). PRD의 대표 예문("김도영이 똥이 마려웠으면")이 제일 웃기지만 실명 + 신체 이야기라 쓰지 않았다.

### 확률 숫자는 히어로에 쓰지 않았다

"삼진 23% → 31%"를 히어로에 박으면 제일 잘 팔리지만, 그 숫자는 엔진이 내야 한다(CLAUDE.md CRITICAL). 홈에서 엔진을 돌리려면 상황 하나를 통째로 세워야 해서 이번 범위를 넘는다. **대신 칩을 눌러 1초 만에 진짜 숫자를 보게 했다.**

### 빈 상자 대신 뼈대

`승부처를 고르는 중…` 글자 한 줄을 실제 승부처 줄과 **같은 크기의 뼈대 두 개**(52px · 반경 8px · 왼쪽 3px)로 바꿨다. 반짝이지 않는다 — 움직임은 결과를 알릴 때만이다(UI_GUIDE 원칙 6). 읽어 주기용 문장은 `.srOnly`로 남겼다.

돌아온 뒤에는 뼈대가 아예 안 뜬다. `useLiveGame`이 받아 둔 경기를 들고 있어서 승부처가 바로 붙는다.

## 확인

- 테스트 **131파일 1,758개 통과**(새 6개), `tsc -b`·`lint` 깨끗, 콘솔 오류 없음
- 390px: 히어로 321px, 제목 28px 넘침 0, CTA 정확히 52px(UI_GUIDE 규격), 칩 가로 스크롤, 가로 넘침 0
- CTA 바탕 `rgb(255, 210, 63)` = `--accent`
- 뼈대 실제 렌더: 380×52px, 반경 8px, 왼쪽 3px `--line-2`, 애니메이션 없음
- 예시 칩 4개 모두 `#/pa/…?t=`로 가고, 토큰이 `{sceneId, texts:[문장], mode:"real"}`로 풀린다
