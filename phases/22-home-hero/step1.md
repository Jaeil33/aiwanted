# Step 1: card-cta

## 왜

사용자 요청: *"이 경기 타석 전체 위에 '이 타석에 TMI 걸기'를 넣으면 좋을것 같아"*

step 0은 **첫 화면 한 판**만 고쳤다. 그 아래로 스크롤하면 피드는 여전히 TMI를 한 번도 말하지 않는다. 승부처 줄(`1회말 무사 1·2루 / 박민우 vs 화이트 ›`)은 **"그 상황 보기"**로 읽히지, "여기서 쓸데없는 한 줄을 걸 수 있다"로는 안 읽힌다.

## 한 일

카드마다 노란 줄 하나를 `이 경기 타석 전체` 바로 위에 넣고, **그 경기의 첫 승부처**로 보낸다.

```
┌ 9.25 (금) 창원 ───────────────┐
│ 한화 7  :  8 NC               │
│ ┌ 1회말 무사 1·2루         › │  ← 특정 승부처 고르기
│ └ 박민우 vs 화이트           │
│ ┌ 9회초 2사 1·2루          › │
│ └ 박정현 vs 신영우           │
│ [  이 타석에 TMI 걸기 ›  ]    │  ← 맨 위 승부처에서 바로 걸기 (노란 테두리 44px)
│ [  이 경기 타석 전체 ›  ]     │  ← 전부 훑기 (회색 테두리 38px)
└──────────────────────────────┘
```

세 층이 생긴다: **고르기 → 바로 걸기 → 더 보기.**

### 꽉 찬 노랑이 아닌 이유

카드가 다섯 개다. 전부 꽉 찬 노랑이면 **한 화면의 주요 버튼이 다섯 개**가 되고, 그러면 히어로의 진짜 주요 버튼이 죽는다(UI_GUIDE 원칙 5 "한 화면에 주요 버튼은 하나"). 그래서 테두리와 글자만 `--accent`, 높이도 히어로(52px)보다 낮은 44px로 뒀다.

꽉 찬 `--accent`는 앱 전체에서 **히어로 CTA 하나**와 타석 화면의 도크 버튼뿐이다.

### 못 받은 경기

승부처를 아직 못 받았으면 흐린 버튼을 두지 않고 **아예 안 단다**. 갈 곳 없는 버튼보다 없는 편이 낫다. `이 경기 타석 전체`는 그대로 있어서 카드가 막다른 길이 되지는 않는다.

## 곁다리로 고친 것

히어로 CTA 테스트가 깨졌다. `getByRole('link', { name: /TMI 걸기/ })`가 카드 버튼 다섯 개까지 잡아서 "여러 개"가 됐다. 이름을 `/아무 타석에나 TMI 걸기/`로 좁혔다.

## 확인

- 테스트 **131파일 1,760개 통과**(새 2개), `tsc -b`·`lint` 깨끗
- 카드 안 링크 차례: `승부처 1` → `승부처 2` → **`이 타석에 TMI 걸기`** → `이 경기 타석 전체`
- 버튼 href가 첫 승부처 href와 **글자까지 같다**(`#/pa/20260925HHNC02026/7`)
- 실제 렌더: 44px · 글자·테두리 `rgb(255, 210, 63)` · 바탕 투명 · `이 경기 타석 전체`와 10px 간격
- 카드 다섯 개 모두 하나씩, 카드 높이 330px, 가로 넘침 0
- 반경 6px(`--r-control`)은 앱의 표준 버튼(`Button.module.css`)과 같은 값이다
