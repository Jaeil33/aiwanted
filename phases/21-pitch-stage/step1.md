# Step 1: frame

## 왜

`/grill-me` Q12(b). 웅장함을 막고 있던 게 그림 실력이 아니라 **한 줄짜리 상수**였다.

```
f = min(폭 기준 1039, 높이 기준 (274 − CAPTION_PX − 27) / 0.2456)
```

`CAPTION_PX = 120`이라 높이 쪽이 516에서 걸려 있었다. 폭은 1039까지 허용하는데 자막이 절반으로 깎고 있었다.

## 한 일

`CAPTION_PX` **120 → 64**. 그러려면 자막이 두 줄이어야 한다.

```
그 전 (세 줄)              지금 (두 줄)
타자 · 우타                양의지 우타
양의지            VS       .253 · OPS .801
타율 .253 · OPS .801
```

역할(`타자`/`투수`)은 자리와 색이 이미 말해 주니까 화면에서 뺐다. 다만 **읽어 주기 위해 글자로는 남겼다**
(`.srOnly`) — 자리와 색은 스크린리더에 없다.

## 번 것

| | 자막 120px | 자막 64px |
|---|---|---|
| 초점거리 `f` | 516 | **744** |
| 홈플레이트에서 1ft | 45px | **65px** |
| 공 반지름 | 5.4px | **7.9px** (step 4에서 ×1.5 → 11.8px) |

존·마운드·홈플레이트·타석 박스·번호 원 위치까지 전부 같은 비율로 커진다. **화면 자리는 1px도 안 늘었다.**

## 확인

`tracker.test.ts`에 못 박았다 — `CAPTION_PX === 64`이고 390×274에서 홈플레이트 1ft가 60px을 넘는다.
실제로 띄워 재니 자막 상자 68px(예약 64 + 흐려지는 4px), 가로 넘침 0.
