TMI 야구 나이트게임 시안

지금 화면은 설명 문서처럼 읽혀서, 경기장과 결과가 나오는 순간을 주인공으로 바꿨어요. 네 화면 모두 8월 11일 창원 KT–NC 9회초 2사 만루 실제 장면과 엔진이 계산한 확률로 그렸어요.

  • 경기장이 화면이다사이트 머리말과 설명 문단을 걷어내고, 중계 카메라 시점의 경기장을 화면 절반 넘게 씁니다.
  • 큰 숫자는 하나만3단 승률 표 대신 줄다리기 게이지 하나. 타석·이닝·경기는 탭으로 바꿔 봅니다.
  • TMI는 카드 한 장문장을 넣으면 카드가 뒤집히며 해석·효과·근거 등급이 한 장에 담깁니다. 등급은 테두리 금속색입니다.
  • 움직임은 결과를 알릴 때만볼·스트라이크 콜, 게이지 이동, 카드 뒤집기, 1,000경기 점 채우기. 나머지는 조용히 둡니다.

글꼴: 콜·큰 제목 Gasoek One · 본문 Noto Sans KR · 숫자 Archivo(좁은 폭). 확률은 모두 현재 TMI 야구 엔진 값이고, 결과 화면의 다시 치른 점수만 예시입니다.

기록·중계: 네이버 스포츠(KBO) · 날씨: Open-Meteo · 확률: TMI 야구 엔진 계산값. 선수 사진·구단 로고는 쓰지 않습니다.
