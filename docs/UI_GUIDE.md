# UI 디자인 가이드 — 나이트게임 (ADR-011)

시각 기준 시안: `docs/design/nightgame/` (로비·플레이·TMI 카드·결과 네 화면). 시안에서 토큰·구성·동작을 옮기되 코드를 import하지 않는다.

## 디자인 원칙
1. **경기장이 화면이다.** 플레이·결과 화면의 절반 이상은 중계 카메라 시점 경기장(캔버스)이다. 사이트 머리말, 설명 문단, 푸터를 두지 않는다.
2. **큰 숫자는 하나만.** 화면마다 가장 중요한 숫자 하나(승률, 나비효과 %p, 1,000경기 승수)만 크게 쓰고 나머지는 작게 쓴다.
3. **숫자 옆에는 이유가 있다.** 확률 옆에 근거 등급(실측·그럴듯함·상상)과 모드(현실·만화)를 붙인다.
4. **TMI는 카드 한 장.** 해석, 세기, 효과, 이유, 등급(테두리 금속색)을 한 장에 담는다.
5. **엄지 하나로 끝난다.** 주요 조작은 하단 도크에 둔다. 버튼 높이는 48px 이상이고, 던지기는 80px 원형이다.
6. **움직임은 결과를 알릴 때만.** 볼·스트라이크·결과 콜, 승률 게이지 이동, 카드 뒤집기, 1,000경기 점 채우기, 로비 조명 켜기에만 쓴다.
7. **실제 경기가 콘텐츠다.** 실제 선수 이름·시즌 기록·구장·날짜를 쓴다. 가짜 수치와 가짜 로고·광고판은 쓰지 않는다.

## 반경·간격·깊이
- 반경: 2px(스코어버그·LED), 6px(버튼·칩·입력·탭), 8px(도크 버튼·TMI 칸·HUD 판), 10px(티켓·결과 판), 12px(TMI 카드), 16px(시트 위쪽 모서리), 50%(던지기 버튼). 다른 값은 쓰지 않는다.
- 간격: 4px 단위(4 · 8 · 12 · 16 · 24 · 32). 형제 간격은 `gap`으로 준다.
- 그림자: 휴대폰 열 외곽과 떠 있는 시트만 `0 40px 80px -30px rgba(0, 0, 0, 0.8)`. 콜 글자에만 딱딱한 그림자 `0 4px 0 rgba(0, 0, 0, 0.55)`.
- 경기장 위 글자 가독성은 스크림(아래로 짙어지는 단색 그라데이션 판)으로 확보한다.

## 화면 구성 (390px 기준)
### 로비 `#/`
- 상단 바 52px: 브랜드 "TMI 야구"(`--ui` 900 17px, '야구'만 `--flood`)와 장면 수.
- 경기장 캔버스 0~400px(로드 때 조명 켜기). 캔버스 아래쪽 스크림 위 히어로 순서:
  1. 눈썹글: "오늘의 명장면", 날짜(요일), 구장
  2. 상황 제목(`--callout` 46px)
  3. 원정·홈 팀 판(팀 색 3px 선, 점수 `--num` 34px)
  4. 승부처 지수(LED 20칸 + 숫자)
  5. 주요 버튼 "경기 입장"
- 다른 명장면: 가로 스크롤 티켓(폭 204px, 절취선 노치, 스크롤 스냅). 담는 것: 날짜·구장, 승부처 지수, 팀·점수, 상황, 주자 다이아몬드.
- 티켓 줄 아래 출처 한 줄(`--dim` 11px).
- 하단 탭바 68px: 명장면 · 판정소 · 만든 이유(아이콘 + 라벨, 현재 탭은 `--chalk`).

### 플레이 `#/scene/:id`
- 경기장 캔버스 0~420px, 전체 폭. 캔버스 위에 겹치는 것:
  - 좌상단 스코어버그: 팀 색 선, 공격 팀 이름은 `--flood`, 점수 `--num` 19px, 이닝 ▲▼, 주자 다이아몬드, B·S·O 점.
  - 우상단 아이콘 버튼 "처음부터"(44px).
  - 가운데 콜(`Callout`).
  - 아래 자막: 타자 이름·타석 방향·타율·OPS | VS | 투수 이름·투구 손·ERA·WHIP.
- 승률 판(캔버스 바로 아래):
  1. 탭(타석·이닝·경기, 기본은 경기)과 TMI 변화 칩(%p)
  2. 좌우 큰 숫자(`--num` 36px), 가운데 무승부
  3. 줄다리기 게이지(12px): 공격 팀 색 | 무승부 빗금 | 수비 팀 색. TMI가 없을 때의 위치에 `--flood` 표시선
  4. 모드 칩, 등급 칩, "TMI 없음 N%"
- TMI 칸 3개: 채운 칸은 금속 테두리 미니 카드(짧은 문장, 손잡이, 효과 %p), 빈 칸은 점선 "+ TMI". 누르면 TMI 시트가 열린다.
- 하단 도크 100px: 이 타석 끝까지(왼쪽) · 던지기(가운데 80px 원형 `--flood`) · 경기 끝까지(오른쪽). 재생 중에는 가운데 버튼이 "건너뛰기"가 된다(ADR-015).
- 기록 목록과 승률 흐름 차트는 "기록" 시트에서 본다(스코어버그를 누르거나 도크 위 "기록" 텍스트 버튼).

### TMI 시트
- 아래에서 올라오는 시트(위쪽 모서리 16px). 뒤 경기장은 55% 어둡게 덮고, 위에 작은 승률 판("전 → 후", 변화 칩)을 둔다.
- TMI 카드(312×344px, 반경 12px, 등급 금속 테두리) 순서:
  1. 머리: "TMI 카드 · AI 해석/규칙 해석"과 등급 칩
  2. 인용 문장(700 18px)
  3. 손잡이 행: 아이콘, 이름▲▼, 대상, 세기 7칸 막대
  4. 효과: 대상 팀 승리확률 전→후, 큰 %p(`--num` 48px)
  5. 이유 한 줄과 "진짜야?"
- 거부 카드는 금속 테두리 대신 `--out` 1px 테두리를 쓰고, 거부 이유와 바꿔 쓸 예시를 담는다. 거부된 문장은 TMI 칸을 차지하지 않는다.
- 카드 아래:
  1. 입력 줄(52px, 글자 16px, 오른쪽 "TMI 걸기" `--flood`)
  2. 카드 수·글자 수
  3. 예시 칩(가로 스크롤)
  4. 모드 전환(현실 / 만화 6배)
- 거부·실패 때 입력을 지우지 않는다.

### 결과 `#/result`
- 위 250px 경기장과 스크림. 그 위 헤드라인 순서:
  1. 눈썹글: 경기 종료, 이닝
  2. `--callout` 64px 헤드라인: "KT 승리", "무승부", "끝내기!"
  3. 최종 점수(`--num` 28px)와 결정 장면 한 줄
- 평행우주 1,000경기: 40×25 점을 공격 팀 승 → 무승부 → 수비 팀 승 순서로 1.4초에 채운다. 범례에는 숫자 26px, "TMI 없이 N", 차이를 쓴다.
- 나비효과 판(금속 테두리): TMI 짧은 문장 → 손잡이, 큰 %p.
- 봉인된 실제 결과: "실제 결과 열기"를 눌러야 열린다. 실제 결과 문장, 최종 점수, 네이버 승리확률 전→후, 출처.
- 도크: "같은 TMI로 다시"(`--flood`) / "결과 카드 공유". 그 위 텍스트 버튼: 다른 장면 · 판정소.

### 판정소 `#/evidence` · 만든 이유 `#/about`
- 로비와 같은 탭바를 쓴다. 표·차트는 `--plate` 판 위에, 숫자는 `--num`으로 쓴다. 본문 폭은 최대 62자.

### 데스크톱 (1024px 이상)
- 가운데 게임 열(최대 480px, 휴대폰 화면과 같은 구성)을 둔다. 양옆은 `--ground`. 2단 대시보드는 쓰지 않는다.

## 움직임
| 순간 | 방법 | 시간 |
|------|------|------|
| 로비 조명 켜기 | 캔버스 조명 세기 0.2→1(짧게 두 번 깜빡임) | 1,100ms |
| 볼·스트라이크·결과 콜 | `Callout`: scale 1.5→1, `skewX(-10deg)`, 머무른 뒤 위로 사라짐 | 1,150ms |
| 승률 게이지 | `flex-basis` 전환, `cubic-bezier(0.16, 1, 0.3, 1)` | 700ms |
| 숫자 | 카운트업(소수 첫째 자리) | 700ms |
| TMI 카드 | 뒷면→앞면 `rotateY(180deg)`, `perspective: 1200px` | 850ms |
| 1,000경기 점 | 채우는 비율 easeOutCubic | 1,400ms |
| 시트 | `translateY(100%)`→0 | 280ms |

- `prefers-reduced-motion: reduce`: 모두 최종 상태로 바로 간다. 캔버스 연출은 1배속, 잔상 없음.
- 금지: 호버 튀어오름, 페이지 슬라이드 전환, 회전 스피너, 반복 반짝임. 대기 동작(투수·타자가 숨 쉬듯 움직임)은 캔버스 안에서만.

## 경기장 캔버스 (ADR-012)
- 중견수 쪽 망원 시점. 위에서부터 그리는 순서:
  1. 관중석: 조명탑 두 개, 관중 점
  2. 백스톱 벽: 검은 LED 띠에 "원정 점수 : 홈 점수 · 상황"을 호박색 글자로
  3. 홈플레이트 흙 원, 타자석 선
  4. 타자(투타에 맞는 타석), 포수, 주심
  5. 앞쪽 마운드와 투수 뒷모습
- 유니폼: 홈 팀은 흰색 바탕에 팀 색 장식, 원정 팀은 회색 바탕에 팀 색 장식. 얼굴 세부·등번호·로고는 그리지 않는다(ADR-005).
- 스트라이크 존: 얇은 `--chalk` 사각형과 3×3 안선(불투명도 18%). 투구 위치 원에는 공 번호와 콜 색을 쓴다.
- 결과 글자(콜·배너)는 캔버스에 그리지 않는다. DOM `Callout`이 그린다.

## 아이콘
- 인라인 SVG, stroke 1.5~2.2, `currentColor`. 야구 요소(다이아몬드, 공, 티켓)와 조작(재생, 빨리 감기, 되돌리기, 공유)에만 쓴다.
