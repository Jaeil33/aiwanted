# PRD: TMI 야구

## 목표
팬들이 경기마다 떠드는 "그날 짜장면 먹어서 졌다" 같은 TMI가 승부를 얼마나 바꾸는지, 실제 KBO 명장면을 다시 치르며 확인하게 한다.
한 줄: **쓸모없는 변수, 진짜 쓸모없을까?**

## 해결하는 문제
- 팬은 징크스·컨디션·날씨 같은 '이유'를 매일 이야기하지만, 그 이유가 실제로 승부를 얼마나 바꾸는지 확인할 곳이 없다.
- 승리확률 같은 야구 데이터는 숫자판이라 어렵고 재미가 없다.
- 그럴듯한 이유와 실제 효과를 구분하는 감각(데이터 리터러시)은 놀이로 익힐 때 가장 오래 남는다.

## 사용자
- 주 사용자: 징크스·밈을 즐기는 KBO 팬. 휴대폰으로 들어온다.
- 보조 사용자: 야구를 잘 모르는 투표 참여자. 해설 문장과 3단 승률만으로 바로 이해해야 한다.
- 심사위원: 30초 안에 무엇을, 왜, AI를 어디에 쓰는지 보여야 한다.

## 한 판의 흐름
1. 로비에서 명장면 고르기 → 2. TMI 한 줄 입력 → 3. TMI 카드(해석·효과·근거 등급)와 승률 게이지 변화 확인 → 4. 한 구씩·이 타석 끝까지·경기 끝까지 다시 치르기(언제든 건너뛰기) → 5. 결과(승패·평행우주 1,000경기·나비효과·봉인된 실제 결과·공유) → 6. "진짜야?"로 판정 보기

## 핵심 기능
1. **명장면**: 2026 시즌 실제 경기의 결정적 순간 최대 16개(선정 4개 + 네이버 승리확률 변화가 큰 타석 자동 추출). 실제 결과는 끝날 때까지 가린다. 날짜로 정해지는 "오늘의 장면". 장면의 투수·타선은 그 타석 첫 투구 시점 기록을 따르고, 승부처 지수는 엔진이 계산한 사전 기대 변화(%p)로 보여준다(ADR-014).
2. **TMI 걸기**: 자유 문장(최대 80자)을 AI가 번역한다. 번역 결과는 조절값(14개 손잡이)·대상·세기(−3~3)·범위(이번 타석/경기 내내)·근거 등급·한 줄 해설이다. 실측 변수(기온·바람 등)에 해당하면 실측 효과를 연결한다. 최대 3개까지 쌓는다. AI를 쓸 수 없으면 규칙 해석으로 대신한다. 실존 선수에게 확실히 민감한 내용만 거부한다. 그 밖의 어떤 입력이든 효과를 1개 이상 만든다(ADR-013): 딱 맞는 규칙이 없으면 문장 분위기로 '상상' 효과를 잇고 그렇게 밝힌다. 거부·실패 때 입력을 지우지 않는다.
3. **승률 게이지(3단)**: 타석(타자 출루 vs 투수 아웃, 볼카운트마다 갱신), 이닝(공격팀 득점 vs 수비팀 무실점, 기대 득점), 경기(승·무·패, KBO 11회 무승부). TMI 전후 차이를 %p로 보여준다. 화면에는 줄다리기 게이지 하나를 크게 두고 타석·이닝·경기는 탭으로 바꾼다.
4. **현실/만화 모드**: 현실은 추정값·설정값 크기 그대로, 만화는 효과를 6배로 과장한다. 모드 라벨을 항상 표시한다.
5. **다시 치르기**: 한 구 / 이 타석 끝까지 / 경기 끝까지. 경기 끝까지는 승부처 타석만 움직이고 나머지는 빨리 감으며, 재생 중 언제든 건너뛰기·처음부터를 쓸 수 있다(ADR-015). 중견수 쪽 중계 카메라 시점(ADR-012)으로 실제 투구 궤적(PTS)·투구 동작·타구·주자를 연출하고 볼·스트라이크·결과를 콜로 알린다.
6. **결과**: 승패, "평행우주 1,000번 중 N번 승리"(정확 확률의 기대값), 실제 결과 공개, 나비효과 점수(승리확률 변화 %p), 공유 카드 이미지.
7. **판정소**: "진짜야?"를 누르면 AI가 TMI에 맞는 실측 변수를 찾아 설명한다. 근거는 2021–2025 학습·2026 검증 결과(효과 크기, 95% 구간, 판정)다. 실측 변수 목록과 엔진 신뢰도(2026 중계 타석에서 네이버 승리확률과 Brier 비교)를 함께 보여준다.
8. **만든 이유**: LG Aimers 투수 제구 예측 대회에서 멘탈·클러치 변수 5개가 모두 효과가 없거나 오히려 점수를 떨어뜨린 경험이 이 게임의 출발점이다. 데이터 출처, 한계, 근거 등급의 뜻을 설명한다.

## 성공 기준 (9/20 제출본)
- 휴대폰(390px)에서 첫 화면부터 첫 TMI 결과까지 30초 이내, 탭 3번 이내
- 모든 확률이 엔진 테스트로 검증됨: 정확 계산과 시뮬레이션 일치, 대칭, 경기 규칙
- AI 해석 실패·거부·오프라인에서도 한 판이 끝까지 진행됨
- 가상 이름 해석 말뭉치에서 무해한 입력의 95% 이상이 뜻에 맞는 방향의 효과 1개 이상을 내고, 무해한 경계 문장 과잉 거부 0, 민감 문장 거부 누락 0
- 장면 16개 모두 한 판(TMI → 한 구 → 경기 끝까지 → 결과)이 헤드리스 브라우저 점검에서 멈춤·콘솔 오류 없이 끝남
- 경기 끝까지 연출은 1탭으로 건너뛸 수 있음
- 실측 변수 판정마다 시간 순 검증(walk-forward) 수치가 붙어 있음

## MVP 제외 사항
- 실시간 경기 연동(라이브 TMI): 운영·권리 부담이 크다
- 공개 랭킹·댓글·닉네임: 실존 선수 TMI를 공개 게시하려면 모더레이션이 먼저 필요하다
- 로그인·결제·친구 실시간 대결
- 음성 캐스터, 3D 경기장, 선수 사진·구단 로고
- 다른 종목

## 디자인
- 나이트게임 중계 게임 화면(ADR-011): 조명탑 아래 경기장이 주인공이고 스코어버그·타자/투수 자막·승률 게이지·TMI 카드가 그 위에 얹힌다. 시안은 `docs/design/nightgame/`. 단일 다크 테마.
- 휴대폰 세로 화면 우선, 1024px 이상은 가운데 게임 열(최대 480px).
- 움직임은 결과를 알릴 때만: 볼·스트라이크 콜, 게이지 이동, 카드 뒤집기, 1,000경기 점, 로비 조명.
- 숫자 옆에는 항상 근거 등급과 모드 라벨을 붙인다.
